# YT-TikTok-Downloader

## Overview

## Features

- **Batch Downloading**: Download multiple videos at once by providing a list of URLs or uploading a text file containing video links.
- **Supports YouTube Shorts and TikTok**: Easily download content from YouTube Shorts and TikTok platforms.
- **High-Quality Downloads**: Automatically selects and downloads the highest available video and audio quality.
- **Graphical User Interface (GUI)**: Simple and intuitive interface built with Tkinter.
- **Progress Logs**: Real-time logging of download progress and statuses.

## Requirements

- **Operating System**: Windows, macOS, or Linux
- **Python**: 3.6 or higher
- **Dependencies**:
  - `yt-dlp`
  - `tkinter` (usually comes pre-installed with Python)
  - `ffmpeg` (required for merging video and audio)
